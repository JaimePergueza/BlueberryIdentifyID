# Enlaces de referencia

- Westerdijk Fungal Biodiversity Institute, *Fungal Biodiversity*.
- Westerdijk Fungal Biodiversity Institute, *Food and Indoor Fungi*.
- Wiley, *The Fusarium Laboratory Manual*.
- PNAS/PubMed, ITS como código de barras primario para hongos.
- UNITE, base de datos de secuencias ITS y Species Hypotheses.
- CellProfiler, identificación y medición de objetos biológicos.
- ilastik, clasificación interactiva de píxeles y objetos.
- scikit-image, propiedades de regiones y esqueletización.
- OpenCV, contornos, círculos y watershed.
- CVAT y Segment Anything, apoyo a la anotación de máscaras.
- DIFaS, DeFungi y OpenFungi, datasets comparables para investigación.

Las referencias completas y el criterio de uso se describen en
`research_identification_sources.md`.
